# cyveura.com

Static landing page for Cyveura and its product Coconut Shield. No build step.

- `index.html`, `assets/css/style.css`, `assets/js/main.js`, `assets/img/` (logos, favicon)
- Product links go to https://coconut.cyveura.com
- Demo, POC and pricing requests go to contact@cyveura.com

Local preview: `python3 -m http.server 8080` in this folder, then open http://localhost:8080
Deploy: push to `main`; GitHub Pages publishes it.
